# Visión — WordPress Static News & Blog Theme

A modern, responsive web template designed as a standalone static front-end prototype for a **WordPress news and editorial blog theme**. Built with **HTML5**, **Custom CSS**, and **Vanilla JavaScript**, this project serves as the visual and structural base for the **Visión** media platform.

## 🚀 Live Demo

Explore the live static prototype here: [https://jesusmoreno71.github.io/vision-blog-theme-wordpress/](https://jesusmoreno71.github.io/vision-blog-theme-wordpress/)

## ✨ Key Features

- **WordPress Theme Prototype:** Designed specifically following editorial WordPress blog structures (hero stories, category feeds, sidebar widgets, and article cards).
- **Static Preview for GitHub Pages:** Fully functional static version allowing instant browser preview without requiring a PHP/WordPress local environment.
- **Editorial Blog Layout:** Clean newsfeed design showcasing primary headline stories, category tags, and post cards.
- **Fully Responsive:** Fluid grid and flexible components adaptable across desktop, tablet, and mobile displays.
- **Interactive Elements:** Mobile navigation toggle, interactive tab switches, and UI state handlers powered by Vanilla JS.

## 🛠️ Tech Stack

- **Target CMS:** WordPress
- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (Custom Stylesheets, Flexbox & CSS Grid)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Deployment:** GitHub Pages

## ⚙️ Local Setup & Preview

To preview this static theme locally:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/jesusmoreno71/vision-blog-theme-wordpress.git](https://github.com/jesusmoreno71/vision-blog-theme-wordpress.git)
   ```

2. **Open the project:**
   Open index.html directly in your web browser or use a local dev server like Live Server in VS Code.


## 📌 Project Purpose
Created to design and prototype the complete user interface for a custom WordPress news theme, ensuring all layout elements, CSS architecture, and JS interactions are polished before migrating template files into native WordPress PHP loops.
